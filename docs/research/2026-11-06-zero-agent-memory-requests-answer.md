# Ответ ZeroAIMemory на предложения zero-agent (2026-11-06)

Исходный документ: [`2026-11-06-zero-agent-memory-requests.md`](2026-11-06-zero-agent-memory-requests.md).
Решение владельца 2026-11-06 (ответ «А»): небольшие исправления — в M6 (`0.0.11-m6`), крупные
функции — в M7 или отдельный этап «Память для своего агента», остальное — по необходимости.

## 1. Принято в M6

| ID | Что делаем | Где в плане M6 |
|---|---|---|
| CR-8 | Учёт MCP берёт сессию из заголовка **или** аргумента `session_id`; `session_id` в схемах `memory_search`, `memory_read`. Подтверждено чтением кода: `mcp/mod.rs:257` смотрит только заголовок | задача 19 (новая) |
| CR-7 | `timeout_ms` в `RecallReq` с верхним пределом из конфигурации; `source`, `agent_block_version` в схеме `memory_recall` | задача 19 |
| CR-20 | `Idempotency-Key` на `POST /nodes`, `PUT`/`PATCH /nodes/{id}` (семантика записей журнала: повтор → 200 и исходный ответ, другое тело → 422); `idempotency_key` в `memory_write` | задача 19 |
| CR-9 (часть) | `/health.features` — официальный способ узнать возможности, флаг на функцию; правило совместимости `/api/v1` в документации. OpenAPI — в M7 | задача 19 + 13c |
| Приложение | `focus` в `memory_read` (7b); захваченная задача в `open` в дайджесте (8a); `brief` субагента без `session_id` гасит подсказки родителя (проверка вместе с эпохами 7a, исправление — 19); README и устаревшие комментарии (13c); префикс `w:` в списках ссылок (19); описание `memory_update_entry` (19); снимок сессии — 17c | разные |

## 2. Перенесено в M7 / отдельный этап

CR-4 (лента изменений), CR-6 (атомарная выдача задачи), CR-10 (дедупликация под гонкой), CR-12
(пакетная запись), CR-19 (происхождение записи), CR-2 (токены с областью), CR-3 (идентичность
субагента), CR-1 (вид `artifact`), CR-18 (утилиты из Knowledge в подсказках), CR-5 (описание
триггеров и маскировки с тестовыми примерами). Причина: это новые сущности и модель безопасности,
им нужно своё ТЗ; проектировать их в конце M6 — риск для качества.

## 3. По необходимости

CR-11, CR-13, CR-14, CR-15, CR-16 — у каждого есть обходной путь; потребности сейчас нет.

## 4. Что в описании неверно

Расхождений пока не найдено; CR-8 подтверждён кодом. Остальные утверждения будут сверены тестами
при реализации (задача 19) и записаны сюда.
