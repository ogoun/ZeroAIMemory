# Исследование 02. MD-движки и RAG в AppFlowy, AFFiNE, Aquilum

Дата: 2026-10-17. Пометка «(по знаниям)» — не проверено по исходникам в сессии.

## AppFlowy — https://github.com/AppFlowy-IO/AppFlowy
- Flutter + Rust-ядро; сервер AppFlowy-Cloud на Rust (actix): Postgres+pgvector, Redis, S3/MinIO, GoTrue, worker, nginx — ~8 сервисов, от 4 ГБ RAM.
- Документ — дерево блоков на CRDT (yrs). Markdown — только импорт/экспорт с потерями (по знаниям).
- Индексация (`AppFlowy-Cloud/libs/indexer/src/collab_indexer/document_indexer.rs`): плоский текст абзацев → склейка до `APPFLOWY_EMBEDDING_CHUNK_SIZE` (2000; при ошибке разбора 1000), overlap 200; только OpenAI `text-embedding-3-small`; **`fragment_id` = xxHash64 содержимого** → инкрементальный переэмбеддинг; очередь + планировщик. Иерархического поиска нет.
- AGPLv3, движение к open-core.

## AFFiNE — https://github.com/toeverything/AFFiNE
- TS (React) + Rust (napi-rs), Electron; сервер NestJS + Postgres/pgvector + Redis + S3. Минимум 2 CPU / 4 ГБ.
- BlockSuite: блоки в Yjs, тяжёлый редактор на Lit.
- Блобы content-addressed (ключ = хэш) (по знаниям).
- RAG (`packages/backend/server/src/plugins/copilot/embedding`): чанки с адресом блока (`blockId/elementId`), выборка topK×2 → `CopilotRerankService` → topK=5; режимы workspace/required(docIds). Self-host AI «не готов».
- MIT (+CLA).

## Aquilum — https://github.com/Freaction/Aquilum
- ~231★, AGPL-3.0-only. Нативный Rust (Masonry + winit + vello_cpu), local-first.
- Хранение: обычные `.md` в vault, вложения рядом; индексы отдельно.
- Поверх markdown — Yjs CRDT: правки агента и человека сливаются дельтами. История: дельты, вехи, откат одной правки, retention, именованные версии; корзина.
- Markdown: frontmatter как поля, wiki-ссылки, задачи, таблицы, callout, Dataview-подобные запросы, граф.
- Поиск: Tantivy + индекс полей frontmatter; без эмбеддингов.
- MCP (stdio + HTTP): группы search/notes/frontmatter/history/trash/workspace; `note_outline`, правка **по разделам**, имя версии при правке, флаг `allow_write`, адресация путём или заголовком.

## Что берём
1. Ключ чанка = хэш содержимого → переэмбеддинг только изменённого (AppFlowy).
2. Чанкинг по заголовкам + breadcrumb и адрес в payload (лучше AppFlowy, по мотивам AFFiNE blockId).
3. Over-fetch + rerank (AFFiNE).
4. Из Aquilum: `outline`, правка по разделу, имя версии, журнал версий с откатом, корзина, адресация путём, read-only токены.
5. Content-addressed блобы (AFFiNE).
6. Frontmatter как индексируемые поля.
7. Web UI: не брать BlockSuite/appflowy_editor; markdown-it/micromark + DOMPurify + CodeMirror 6.

## Что не берём
- CRDT — для агентов достаточно оптимистической блокировки (rev/ETag, 409) + журнал ревизий.
- Блочную JSON-модель — источником истины остаётся markdown.
- Стек Postgres+Redis+S3+воркеры, Electron/Flutter, канвас.
- Код AGPL-проектов (AppFlowy, Aquilum) не копировать, только идеи.
