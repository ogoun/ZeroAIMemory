# M7.5. Качество поиска и подсказок — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вернуть полноту выдачи ТС-1 и честный порядок `reliable_first`, сделать подсказки без
модели и к ошибкам точнее, научить FTS датам, карту кода — своему коду, добавить уборку памяти
(предложения человеку), закрыть замечания переноса AIIndicators — и выпустить `0.0.18-m7.5`.

**Architecture:** Миграций нет. Поиск и подсказки меняются ключами с умолчанием «как 0.0.17»,
пока правило выбора, записанное до прогона, не выбрало иное. Уборка — новый вид внутренних работ
`tidy` на общем пакете §6.3 и новый тип предложений; применяет только человек в WebUI. Триггеры
сопоставляются одним модулем `zam_search::triggers` для `brief` сервера и `pre-tool` клиента.

**Tech Stack:** Rust (axum, tokio, rusqlite, globset, regex, jiff, serde, clap), Svelte 5 (руны),
TypeScript, Vite, size-limit, Playwright (Microsoft Edge).

**Spec:** `docs/specs/2026-11-21-m7-polish.md` §3 (ограничения этапа) и §8 (волна M7.5); номера
пунктов ниже — её. Решения координатора — §12 пп. 114–135. Проект и план — без ревью и пре-флайта
(решение 114).
