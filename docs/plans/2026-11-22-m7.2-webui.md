# M7.2. WebUI — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сделать WebUI удобным на телефоне и планшете (в первую очередь доску задач), показать
число записей в разделах и прогресс общих задач по подзадачам `part_of`, вывести в WebUI копии
сервера, `no_recent_backup`, журнал аудита и импорт архива, показать выдачу без сессии в CLI,
WebUI и `xtask ab`, дать правку и корзину записей журналов и локальный граф связей — и выпустить
`0.0.15-m7.2`.

**Architecture:** Каркас вёрстки WebUI — один источник ширин (`web/src/lib/layout.ts`), классы
ширины окна для шапки и дерева, раскладка «список — карточка» по ширине области журнала
(`JournalSplit.svelte`, container query), правила сенсорного ввода `(pointer: coarse)`. Сервер —
поверх существующих механизмов: счётчики по индексам `entries_feed`, дерево подзадач по рёбрам
`edges` в Rust, копия в процессе тем же `backup::backup` с общим замком автокопий, фильтры лент
и сессий. Миграций нет, инструментов MCP по-прежнему 11, блок v8 и хуки не меняются.

**Tech Stack:** Svelte 5 (руны), TypeScript, Vite, size-limit, Playwright (установленный
Microsoft Edge), Rust (axum, rusqlite, serde, clap, tokio).

**Spec:** `docs/specs/2026-11-21-m7-polish.md` §3 (общие ограничения) и §5 (волна M7.2); номера
пунктов ниже — её.
