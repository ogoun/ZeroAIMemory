# M7.4. Администрирование сервера — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Дать администратору сервера памяти проверку и восстановление без ручной работы —
контрольные суммы миграций и сверку схемы, `zam-server rollback --to v<N>`, исправленный
`restore`, сборщик мусора блобов, `zam-server doctor`; закрыть мелкие долги API и CLI (фильтры
аудита, сводка работ, ручные пробы, версии компонентов) и WebUI администрирования — и выпустить
`0.0.17-m7.4`.

**Architecture:** Номерных миграций нет: суммы — служебная таблица мигратора `zam_migrations` в
обеих базах; открытие без изменений и сверка схемы с эталоном `:memory:` — модуль
`zam_store::inspect`, его берут `rollback` и `doctor`. Откат и восстановление — один набор
переносов в `backups/pre-*` (ничего не удаляется). Сборщик — проход воркера обслуживания по
`mtime` файлов под замком блобов пользователя, удаление двухфазное через `.gc/`. `doctor` —
только чтение по умолчанию, `--fix` — безопасное на остановленном сервере.

**Tech Stack:** Rust (axum, tokio, rusqlite, sha2, serde, clap, jiff), Svelte 5 (руны),
TypeScript, Vite, size-limit, Playwright (Microsoft Edge).

**Spec:** `docs/specs/2026-11-21-m7-polish.md` §3 (общие ограничения этапа) и §7 (волна M7.4);
номера пунктов ниже — её. Решения координатора — §12 пп. 97–113. Проект и план — без ревью и
пре-флайта (решение 97).

   сервер 0.0.16 после отката открывает базы с `zam_migrations`. Тесты — задача 2
