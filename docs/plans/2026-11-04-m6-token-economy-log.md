## Уточнить у владельца

До ответа действует вариант по умолчанию (рекомендация).

1. **Где хранить текст снимка сессии** (спецификация, «Вопросы редакции 4», п. 1). А — на сервере
   после маскировки, до 16 КиБ (рекомендация); Б — только локально, 7 дней.
2. **Образцы журналов агента для фикстур** (там же, п. 2; задача 17, шаг 0). А — разрешить прочитать
   по одному свежему журналу Claude Code и Codex, фрагменты обезличиваются (рекомендация); Б —
   владелец кладёт обезличенные фрагменты в `crates/zam-cli/tests/fixtures/transcripts/`; В — не
   давать, критерий снимка остаётся открытым.
3. **Чек-лист на живом агенте** (не блокирует): передаётся ли `CLAUDE_CODE_SESSION_ID` процессу MCP;
   передаёт ли Codex `transcript_path` в хуки; приходит ли `SessionEnd` у Claude Code при закрытии
   окна; цепочка процессов хука и MCP у Codex (общий предок, §7.1).
4. **Прогон агентного A/B** (задача 12) — владельцем, ≥ 10 задач × 2 плеча × 2 повтора, после
   финализации; приёмку M6 не блокирует.
5. **Вопрос 11 M5.7** («Предложено вернуть» в ленте идей): при ответе Б значок добавляется в
   задаче 16.
