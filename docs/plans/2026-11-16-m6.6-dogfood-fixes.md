# M6.6. Недочёты обкатки — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрыть открытые замечания обкатки M6.5 (подсказки, дайджест, пакеты, словарь, Vault,
MCP, CLI, подключение, тесты) и выпустить `0.0.13-m6.6`.

**Architecture:** Правки точечные, поверх существующих механизмов: подсказки к запросу — новый
модуль `api/recall/prompt.rs` после выноса идей из `recall.rs`; дайджест — `trap_cands` и строка
задач; Vault — маршрут `POST /vault/{id}/move`; остальное — CLI, MCP и протокол `zam guide`.
Миграций нет, инструментов MCP по-прежнему 11, блок v8 не меняется.

**Tech Stack:** Rust (axum, rusqlite, serde, clap), SQLite, tree-sitter (карта кода), Markdown
протокола.

**Spec:** `docs/specs/2026-11-16-m6.6-dogfood-fixes.md` (§ ниже — её разделы). Подробная карта по
коду с номерами строк на `34fde29` — `.tmp/m66/map-cli.md` и `.tmp/m66/map-server.md` (вне git;
исполнитель читает раздел своей задачи; номера строк сверять с кодом — после задачи 1 строки
`recall.rs` сдвигаются).

## Global Constraints

- **Ветка и версия.** Ветка `m6.6-dogfood-fixes`, версия выпуска `0.0.13-m6.6`.
- **Без миграций** базы пользователя и `system.db`.
- **MCP.** Инструментов 11. Описание каждого инструмента и каждого поля схемы (рекурсивно) — не
  длиннее 300 символов.
- **Блок инструкции v8** не меняется (500/497 токенов из 500). Новые правила — только в протокол:
  `crates/zam-server/src/agent_setup/guide.ru.md` и `guide.en.md` синхронно.
- **Совместимость** — `docs/api-compat.md`: новые поля ответа и маршруты — без флага, кроме
  `vault_move` (флаг в `features`, `api/health.rs` `FEATURES`, тест `health_features_documented`).
  Старый сервер для новой команды CLI — код 1 с текстом «… нужен zam-server 0.0.13-m6.6 или
  новее».
- **Дайджест детерминирован** (`recall_frozen`), предел канала тяжёлого профиля — `recall_heavy*`.
- **Тексты ответов агенту** — время `yyyy-MM-dd HH:mm:ss` UTC без `T`, `Z` и смещения
  (`zam_core::time::agent_ts`).
- **Правила проекта:**
  - временные файлы — только внутри проекта под `.gitignore` (`.tmp/`, `target/`); запрещены
    `/tmp`, `%TEMP%`, `AppData\Local\Temp`, scratchpad, `tempfile` без `dir=`;
  - коммиты — только явными путями (`git commit -m … -- <пути>`), без `-a`, `add -A`, `add .`,
    без `git stash`;
  - адреса LAN, пароли и токены — не в коммиты (репозиторий публичный); в тестах — адреса RFC 5737;
  - фиктивные ключи в тестах сканеров собирать из частей во время выполнения (push protection);
  - текст с обратной косой и NUL — инструментами Write/Edit, не heredoc; журналы и Markdown — LF;
  - сборка: `. scripts/dev-env.ps1`, `CARGO_TARGET_DIR=target\m65`, `-j 2`,
    `CARGO_INCREMENTAL=0`; интеграционные тесты — `cargo test -p <крейт> --test X`; полный
    прогон — только координатор;
  - процессы владельца (UAGame, UnrealEditor, его python) не трогать; LNK1104 — новый
    `CARGO_TARGET_DIR`;
  - свободное место на H: перед долгой сборкой — не меньше 30 ГБ.
- **Журнал этапа** — `docs/plans/2026-11-16-m6.6-dogfood-fixes-log.md`: задача добавляет раздел
  «Задача N» (решения исполнителя с пометкой «[решение исполнителя, задача N]», прогоны).
  CHANGELOG — раздел `## [Unreleased]` (задача 13 переименует его в `## [0.0.13-m6.6] - <дата>`),
  каждая задача — свои пункты.
