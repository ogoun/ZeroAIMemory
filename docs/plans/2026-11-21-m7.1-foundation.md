# M7.1. Опора и безопасность — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Снять внешний риск сборок (ONNX Runtime с GitHub удалён), закрыть утечки секретов в
выдаче агенту, ввести ключ по адресу сервера, убрать шум подсказок и флейки тестов — и выпустить
`0.0.14-m7.1`.

**Architecture:** Правки поверх существующих механизмов: загрузчик `xtask fetch-deps` и
манифесты `deploy/`; правила сканера `zam-secrets` (один источник правил для клиента и сервера) и
маскировка на путях выдачи агенту по токену; поиск настроек подключения `zam-cli/src/locate.rs`;
строка очереди разбора `api/recall/ideas.rs`; хук `post-tool`. Миграций нет, инструментов MCP
по-прежнему 11, блок v8 не меняется.

**Tech Stack:** Rust (axum, rusqlite, serde, clap, regex, zip), SQLite, Qdrant, GitHub Actions.

**Spec:** `docs/specs/2026-11-21-m7-polish.md` §3 (общие ограничения) и §4 (волна M7.1); номера
пунктов ниже — её.

## Global Constraints

- **Ветка и версия.** Ветка `m7.1-foundation`, версия выпуска `0.0.14-m7.1`.
- **Без миграций** базы пользователя и `system.db` (повышение `RULES_VERSION` — механизм
  перемаскировки `secrets_scanned_v*`, не миграция).
- **MCP.** Инструментов 11. Описание каждого инструмента и каждого поля схемы (рекурсивно) — не
  длиннее 300 символов.
- **Блок инструкции v8** не меняется (500/497 токенов). Новые правила — только в протокол:
  `crates/zam-server/src/agent_setup/guide.ru.md` и `guide.en.md` синхронно.
- **Совместимость** — `docs/api-compat.md`: изменение выдачи агенту — признак в `/health.features`
  (`api/health.rs` `FEATURES`, тест `health_features_documented`).
- **Бюджеты хуков** §10.3 не растут. Тексты агенту — время `zam_core::time::agent_ts`.
- **Правила проекта:**
  - временные файлы — только внутри проекта под `.gitignore` (`.tmp/`, `target/`); запрещены
    `/tmp`, `%TEMP%`, `AppData\Local\Temp`, scratchpad, `tempfile` без `dir=`;
  - коммиты — только явными путями (`git commit -m … -- <пути>`), без `-a`, `add -A`, `add .`,
    без `git stash`;
  - адреса LAN, пароли и токены — не в коммиты (репозиторий публичный); в тестах — адреса RFC 5737;
  - фиктивные ключи в тестах сканеров собирать из частей во время выполнения (push protection);
  - текст с обратной косой и NUL — инструментами Write/Edit, не heredoc; журналы и Markdown — LF;
  - сборка: `. scripts/dev-env.ps1`, свой `CARGO_TARGET_DIR` на задачу (`target\m71-t<N>`),
    `-j 2`, `CARGO_INCREMENTAL=0`; интеграционные тесты — `cargo test -p <крейт> --test X`;
    полный прогон workspace — только координатор;
  - процессы владельца (UAGame, UnrealEditor, его python, qdrant.exe на 6333) не трогать;
    LNK1104 — новый `CARGO_TARGET_DIR`;
  - свободное место на H: перед долгой сборкой — не меньше 30 ГБ.
- **Журнал этапа** — `docs/plans/2026-11-21-m7-polish-log.md`: задача добавляет раздел
  «M7.1 · Задача N» (решения исполнителя с пометкой «[решение исполнителя, задача N]», прогоны).
  CHANGELOG — раздел `## [Unreleased]` (задача 10 переименует его в `## [0.0.14-m7.1] - <дата>`).

## Review Focus

1. **Русский текст с похожими на ключ словами** — «ключ идемпотентности: abc123», «токенов:
   1500», «токен — это строка», `token_id: 01M7…` не маскируются; «токен: <64 hex>» —
   маскируется. Тест — задача 3, `ru_key_value_masked_and_guards`.
2. **Дочитывание `range` после маскировки** — адрес из `[пропущено: …]` в ответе агенту
   дочитывается тем же агентом и даёт тот же (маскированный) текст; адрес чужой ревизии — прежняя
   ошибка. Тест — задача 5.
3. **Старый домашний конфиг** (`url` и `token` верхнего уровня) после обновления клиента работает
   без `zam init`; `zam init` второго сервера сохраняет ключ первого. Тест — задача 2,
   `home_config_legacy_and_two_servers`.
4. **`grep` с кодом 1 внутри конвейера** (`grep x f | wc -l`) — по-прежнему не ошибка только для
   простой команды; `grep` с кодом 2 (нет файла) — ошибка. Тест — задача 8,
   `expected_exit_code_only_simple_command`.
5. **Сборка без кэша** — `xtask fetch-deps` на пустом `target/deps-cache` скачивает ORT из NuGet,
   хэш совпадает, файлы на прежних местах. Проверка — задача 1, прогон CI с новым префиксом
   ключа кэша.
