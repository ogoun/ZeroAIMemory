# M7.3. Внутренние работы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Дать памяти исполнителя внутренних работ (выкл / агент / подключённая модель по
OpenAI-совместимому Chat Completions), ночную проверку поиска и подсказок на своих пробах с
вердиктом и строкой при регрессии, событие «агент открыл подсказку» и кандидатов в Rules, которых
принимает человек, — и выпустить `0.0.16-m7.3`.

**Architecture:** Одна миграция `0027_internal_works.sql` — только новые таблицы. Ночная часть —
отдельная задача сервера `NightRunner` (тик раз в минуту, окно ночи по `[works] at`/`tz`): сначала
проверка всех пользователей тем же кодом поиска и `/recall` без учёта, затем работы. Работа — строка
очереди `works`; один построитель пакета и одна проверка итога для агента (MCP `memory_recall
event=work` → `memory_log kind=work`) и для модели (`ureq` в `spawn_blocking`, маска, второй скан,
закреплённый адрес). Итог работ — только пробы и предложения; знания меняет человек в WebUI.

**Tech Stack:** Rust (axum, tokio, rusqlite, serde, clap, `ureq` 3, `jiff` с `tzdb-bundle-always`,
`blake3`, `zam-secrets`, `zam-markdown`), Svelte 5 (руны), TypeScript, Vite, size-limit, Playwright
(Microsoft Edge).

**Spec:** `docs/specs/2026-11-21-m7-polish.md` §3 (общие ограничения этапа) и §6 (волна M7.3);
номера пунктов ниже — её. Решения координатора — §12 пп. 32–78 (пп. 66–78 и правка пп. 38, 56 —
по пре-флайту плана, `.superpowers/sdd/2026-11-23-m7.3-internal/preflight.md`, вне git).
