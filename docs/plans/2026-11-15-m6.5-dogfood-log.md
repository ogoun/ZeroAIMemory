# M6.5 «Обкатка» — журнал этапа

Этап начат 2026-11-15 по плану владельца после выпуска `0.0.11-m6`:

1. развернуть сервис памяти на сервере в локальной сети (Debian 13);
2. создать в нём решение «ZeroAIMemory» и внести все данные во все нужные разделы;
3. подключить этот репозиторий к памяти;
4. продолжать разработку, пользуясь памятью, фиксируя недочёты и исправляя их по ходу.

Там же владелец попросил разбор идей по состоянию: идея приходит «Непросмотрено», агент
периодически её изучает, сверяет с планом, ТЗ и сделанным и либо вносит в план, либо
возвращает человеку на доработку с описанием, чего не хватает, либо отклоняет с причиной.

Ветка `m6.5-dogfood` от `main` (`e391440`, `v0.0.11-m6`). Версия выпуска этапа — `0.0.12-m6.5`
**[решение исполнителя]**: правки обкатки и разбор идей не ждут M7.

Адреса, пароли и токены в этот журнал не пишутся (репозиторий публичный): адреса стендов — в
Vault памяти и в локальной памяти агента.

## Развёртывание (2026-11-15)

- Сервер: контейнер Proxmox (LXC), Debian 13.7, 4 CPU, 8 ГБ, 320 ГБ ZFS, без GPU, чистый.
  Комплект `zam-server-0.0.11-m6-linux-x64-cpu.tar.gz` и модель `bge-m3-int8` из черновика
  выпуска (SHA-256 сверены по `SHA256SUMS`) — по `deploy/README-install.md`, «Linux»:
  `/opt/zeroaimemory`, пользователь `zam`, данные `/var/lib/zeroaimemory`, конфиг
  `/etc/zeroaimemory/config.toml` (`ml.device = "cpu"`, `[backup] schedule = "daily"`),
  `zam-server service install`. Векторный поиск — `bge-m3-int8`, счётчик токенов — модель.
- Пароль администратора WebUI — случайный, только в файле root на сервере; пользователь
  владельца создан админ-API, начальный пароль WebUI — со сменой при первом входе.
- Клиент `zam` на машине владельца — `%LOCALAPPDATA%\Programs\zam` (PATH пользователя,
  `ZAM_MACHINE`); `zam init --agent claude` в корне репозитория: решение «ZeroAIMemory».
  `CLAUDE.md`, `.mcp.json`, `.claude/settings.json`, `.zeroaimemory/` — в `.git/info/exclude`
  (локально): блок содержит адрес сервера в LAN (замечание 1).
- Запись агента в Rules включена администратором на время заполнения памяти.
