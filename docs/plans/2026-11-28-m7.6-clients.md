# M7.6. Клиенты и интеграции — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрыть последнюю волну этапа M7: перенос памяти при подключении проекта, родной протокол
Anthropic Messages, предложения нативного клиента ZeroAgent (CR-21…26), надёжный клиент снимка
сессии, подключение без следа в репозитории, CLI идей — и выпустить `0.0.19-m7.6` с итогом этапа.

**Architecture:** Миграций нет: новое в снимке — поля JSON `session_snapshots.data`, протокол —
значение настройки. Новые возможности — по признакам `/health.features`; без признака и без новых
полей запроса поведение побайтово как 0.0.18. MCP — 11 инструментов без новых полей схем.
Протокол Anthropic — второй разбор в клиенте подключённой модели поверх общего маршрута, пределов
и журнала отправок M7.3.

**Tech Stack:** Rust (axum, tokio, rusqlite, ureq, serde, clap, rmcp, jiff), Svelte 5 (руны),
TypeScript, Vite, size-limit, Playwright (Microsoft Edge).

**Spec:** `docs/specs/2026-11-21-m7-polish.md` §3 (ограничения этапа) и §9 (волна M7.6); номера
пунктов ниже — её. Решения координатора — §12 пп. 136–143 (задача 1) и 144–165. Проект и план — без
ревью и пре-флайта (решение 144).
