# ZeroAIMemory: протокол работы агента с памятью

Краткие правила — в блоке ZeroAIMemory в CLAUDE.md / AGENTS.md. Здесь — подробности.

## Подключение

- Адрес сервера — строка `ZeroAIMemoryUrl=` в блоке (или `ZAM_URL`). Токен — переменная `ZAM_TOKEN` или `~/.zeroaimemory/config.toml`; в CLAUDE.md, AGENTS.md и `.mcp.json` его нет.
- Решение — `.zeroaimemory/solution.toml` (`agent_solution_id`, `name`); его создаёт `zam init`. Все клоны с этим GUID делят одну память.
- MCP — `<url>/mcp` (streamable HTTP, `Authorization: Bearer`, заголовок `X-Zam-Solution`). Без HTTP-транспорта — `zam mcp` (stdio-прокси). Без MCP — CLI `zam`, без CLI — REST `/api/v1`.

## Поиск: четыре шага с экономией токенов

Каждый следующий шаг — только если на предыдущем не хватило данных.

0. **Кэш.** `memory_search` сначала ищет готовую выжимку. Строка `[cache] «…» — выжимка …, все актуальны` — используй её и дальше не иди. `[cache, stale: …]` — перечитай только изменившиеся источники и обнови выжимку.
1. **Карточки** (`mode=brief`): по строке на кандидата — id, путь › секция, оценка, `rev`, дата, `~N tok`, фрагмент. Префиксы id: `n:` заметка, `i:` insight, `c:` changelog, `r:` релиз. `(seen)` — уже выдано в этой сессии, повторно не читай. Ранжируй карточки сам по смыслу задачи.
2. **Точечное чтение** — `memory_read` одним вызовом нескольких id (до 20). Для каждого: `tier=L0|L1|L2`, `section` (путь заголовков `A > B`), `max_tokens`, `if_rev` (ревизия не изменилась — `unchanged` без текста). Сначала L1 или секция, полный текст — только при необходимости. Бюджет ответа по умолчанию — 1500 токенов.
3. **Выжимка** — `memory_cache_put {query, summary, sources}`: Markdown до 600 токенов со ссылками; `sources` — id (и секции) того, на чём выжимка реально основана. Сервер фиксирует ревизии источников и сам инвалидирует выжимку при их изменении. Ценное надолго — `promote` в заметку или insight.

Каждый ответ оканчивается строкой `~N tok` — это твой расход. Перед новым поиском по той же теме сначала проверь кэш.

## Запись

- **Заметки** — `memory_write {path, content | ops, base_rev?, message?, l0?}`; путь `[<пространство>:/]<путь>`. Без `base_rev` — создание, с ним — замена или правка. Давай заметке `l0` — однострочную сводку.
- **Журналы решения** — `memory_log`:
  - `changelog` — изменение проекта (что и зачем);
  - `insight` — открытие: `gotcha` (ловушка), `failure` (провал), `experiment` (с результатом), `discovery`; `scope=global`, если знание не про этот проект; `triggers` (`file_glob:**/*.sh`, `command_regex:…`, `error_regex:…`) — когда показать подсказку;
  - `release` — релиз.
- **Правка записи** — `memory_update_entry {id, rev, action}`: `supersede` (замена новой), `retract` (отзыв с причиной), `revisit`, `certify`, `append`, `feedback`. `rev` обязателен: без него — 428, при чужой правке — 409 с текущей ревизией. На 409/428 перечитай запись и повтори.
- **Связи** — `memory_link {src, type, dst}`: `links_to`, `relates_to`, `depends_on`, `part_of`, `caused_by`, `fixes`, `derived_from`, `mentions`.
- **Секреты** — только `memory_vault` (`get | set | list`). Значения не попадают в поиск, выжимки и журналы; не копируй их в заметки.

## Достоверность записей

- `certainty`: `axiom` — принятая истина, `theorem` — доказано или проверено, `hypothesis` — предположение. Меняется с `reason`.
- `axiom` ставь, правь и снимай **только по прямому указанию пользователя**. Если по своему выводу считаешь иначе — запиши `hypothesis` или `theorem` рядом (с возражением и доказательствами) и сообщи пользователю.

## Проактивное вспоминание

- Строки `ZeroAIMemory: …` в контексте — подсказки из памяти: правила, ловушки, прошлые сбои. Учитывай их, при необходимости читай по id.
- С хуками (`zam hook …`, их ставит `zam init`) подсказки приходят сами: в начале сессии (дайджест), по промпту, перед правкой файла или командой, после ошибки. Перед завершением хук напомнит записать итог, если были правки, а записей в память не было.
- Без хуков вызывай `memory_recall` сам: в начале работы (`session_start`), перед новым типом файла и после ошибки (`post_tool` с текстом ошибки).

## Пространства

- Решение (GUID из `solution.toml`) — память проекта; Knowledge — общие знания пользователя; Rules — правила, которые читаются в начале каждой сессии (запись агентом — если её разрешил администратор); Human — заметки человека, агенту недоступны.
- Чужое решение по GUID — запрос доступа владельцу; пока он не подтверждён, запись даёт 403.

## Блок инструкции

Блок в CLAUDE.md / AGENTS.md помечен `<!-- zeroaimemory:begin vN -->`. Если сервер сообщил, что блок устарел, — обнови его: `zam init` (или WebUI «Подключение агента»). Текст вне блока `zam init` не трогает.
