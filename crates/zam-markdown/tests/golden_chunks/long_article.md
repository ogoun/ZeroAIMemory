# Индексация заметок

Индексатор обрабатывает заметку номер 1 и строит чанки по секциям. Каждый чанк получает путь заголовков, т. е. контекст для поиска. Длина чанка ограничена бюджетом токенов, и это важно для модели эмбеддингов. Подробнее см. рис. 1 в приложении. Перекрытие в одно предложение сохраняет связность соседних чанков.
