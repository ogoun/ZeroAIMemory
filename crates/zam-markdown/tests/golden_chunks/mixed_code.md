# Пример на Rust

Функция `split_sentences` не режет код вроде `a. B` и путь ./src/main.rs. Вызов см. ниже.

```rust
fn main() {
    // Комментарий. С точкой.
    println!("Привет, мир. Ещё");
}
```

После кода — объяснение: URL https://example.com/a?b=1. Готово.
