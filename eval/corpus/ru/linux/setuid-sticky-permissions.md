# setuid, setgid и sticky bit: шпаргалка

Специальные биты прав — четвёртая восьмеричная цифра перед обычными тремя.

| Бит | Число | На файле | На каталоге |
|---|---|---|---|
| setuid | 4000 | программа выполняется с правами владельца файла | не используется |
| setgid | 2000 | выполнение с правами группы файла | новые файлы наследуют группу каталога |
| sticky | 1000 | не используется | удалять файл может только его владелец (как в `/tmp`) |

В выводе `ls -l` это `s` вместо `x` у владельца или группы и `t` у прочих; заглавные
`S`/`T` означают, что бит стоит, а права на выполнение нет — почти всегда ошибка.

```sh
chmod u+s /usr/local/bin/tool     # или chmod 4755
chmod g+s /srv/shared             # общий каталог команды
find / -xdev -perm -4000 -type f  # аудит setuid-файлов
```

Важно: ядро Linux игнорирует setuid у скриптов с shebang — работает только для
бинарников. Файловые системы, смонтированные с `nosuid`, бит тоже игнорируют. Вместо
своих setuid-программ лучше `sudo` с узким правилом или capabilities
(`setcap cap_net_bind_service=+ep` для привязки к порту ниже 1024).
