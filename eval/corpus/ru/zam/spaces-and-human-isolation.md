# Пространства памяти и изоляция Human

Память пользователя — это несколько корней дерева (пространств). В WebUI они закреплены сверху
в таком порядке: Rules, Human, Knowledge, ниже — решения.

| Пространство | Кто пишет | Доступ агента | Векторный индекс |
|---|---|---|---|
| Rules | человек; агент — только с токеном `rw` и при `rules.agent_write = true` (по умолчанию выключено) | читает, подмешивается на старте сессии | да |
| Human | только человек через WebUI | **нет никакого** | **нет**, только FTS для поиска в WebUI |
| Knowledge | агент и человек | читает и пишет | да |
| Решения (Solutions) | агент и человек | читает и пишет | да |

## Knowledge и решения

Knowledge — знания пользователя, общие для всех проектов: приёмы, особенности окружения,
инсайты с `scope = global`. Пространство решения — память одного проекта. Проект
определяется файлом `.zeroaimemory/solution.toml` с полями `id` (GUID) и `name`; все клоны и
каталоги с тем же GUID на любых машинах делят одну память. CLI ищет этот файл, поднимаясь от
текущего каталога вверх. В монорепозитории подкаталог объявляет область файлом
`<subdir>/.zeroaimemory/area.toml` (`area = "services/parser"`), это метка записей, а не отдельное
пространство.

У каждого решения есть журналы `Changelog`, `Releases`, `Insights` и `Vault` (этап M3). Они
привязаны к решению, а не к сессии; сессия — атрибут записи.

## Адресация из CLI

Цель команды — `[пространство:]путь`: `knowledge`, `rules`, `human`, `solution` или GUID.
Без префикса берётся текущее решение, а без `solution.toml` — `knowledge`:

```
zam tree knowledge:
zam read "rules:Код/Стиль"
```

## Почему Human так строго

Human — личное: черновики, заметки «для себя». В ТЗ это анти-цель: если содержимое Human
попадёт в векторный индекс, в выдачу по токену или в логи — это провал, даже если остальное
работает. Отсюда:

- запросы по токену к Human отвечают отказом в любом виде;
- узлы Human не получают заданий индексации (`index_state = 'excluded'`), в Qdrant их нет;
- поиск Ctrl+K в WebUI находит их только через FTS — и только администратору.

Изоляцию проверяет e2e: Human нет в Qdrant, в выдаче по токену и в логах.
