# HyDE: поиск через гипотетический документ

Gao, Ma, Lin, Callan (2022). Идея: вместо эмбеддинга короткого вопроса языковая модель сначала пишет правдоподобный ответ-абзац, и уже он кодируется и ищется. Ответ может содержать фактические ошибки — это неважно, нужен его «стиль и лексика», похожие на настоящие документы.

Обычно генерируют несколько гипотез, усредняют их векторы вместе с вектором исходного вопроса.

Плюсы: заметный выигрыш в режиме без обучающей разметки (zero-shot), особенно когда вопросы короткие, а документы длинные.

Минусы:

- задержка и стоимость вызова LLM на каждый запрос;
- галлюцинация может увести в сторону: модель «знает» неверный термин и ищет по нему;
- для запросов-идентификаторов бесполезен, там нужен лексический поиск.

Связано: query2doc (дописывание запроса псевдодокументом для BM25), классическое расширение запроса — в отдельной английской заметке.
