# Service worker витрины и кэш браузера

Витрина магазина регистрирует service worker, чтобы повторный вход открывался быстро и при
плохой связи. Ниже — как устроено кэширование и как выкатывать новые версии.

## Что кэшируется

Статика сборки — JS, CSS, шрифты — имеет хеш в имени файла и кэшируется навсегда: новая версия
получает новое имя. Картинки товаров кэшируются на неделю. Ответы API service worker не кэширует,
за исключением справочника категорий.

## index.html

Страница-оболочка `index.html` не должна жить в кэше дольше одного захода: в ней ссылки на
файлы текущей сборки. Для неё стратегия «сначала сеть», кэш — только запасной вариант без
связи.

## Обновление service worker

Новый service worker устанавливается в фоне и ждёт, пока закроются все вкладки со старым.
Витрина показывает плашку «Доступна новая версия» и по нажатию вызывает `skipWaiting`, после
чего страница перезагружается.

## Отладка

В DevTools на вкладке Application видно активный и ожидающий service worker, содержимое
Cache Storage и можно включить «Update on reload» для разработки.
