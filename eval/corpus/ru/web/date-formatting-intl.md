# Даты и время в интерфейсе витрины

Сервер отдаёт моменты времени в UTC в формате RFC 3339, а даты без времени — строкой
`ГГГГ-ММ-ДД`. Интерфейс показывает их в часовом поясе и на языке посетителя.

## Форматирование

Для вывода используется `Intl.DateTimeFormat` с языком из настроек витрины. Форматтеры
создаются один раз и переиспользуются: создание форматтера на каждую строку таблицы заметно
тормозит длинные списки.

## Часовой пояс

Пояс берётся из `Intl.DateTimeFormat().resolvedOptions().timeZone`. Для дат доставки пояс
другой — пояс склада, его присылает сервер вместе с заказом.

## Относительное время

«5 минут назад» формирует `Intl.RelativeTimeFormat`. Значение пересчитывается раз в минуту
общим таймером, а не таймером на каждый элемент.

## Ввод дат

Поле выбора даты отдаёт строку `ГГГГ-ММ-ДД` и в таком виде уходит на сервер, без превращения
в объект времени.
