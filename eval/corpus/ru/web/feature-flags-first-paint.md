# Флаги функций во фронтенде витрины

Новые функции витрины выкатываются за флагами: включить можно для доли посетителей, для
сотрудников или для одного региона. Фронтенд получает значения флагов с сервера и не вычисляет
их сам.

## Откуда фронтенд берёт флаги

При загрузке страницы приложение запрашивает `/api/flags` и кладёт ответ в общее хранилище
состояния. Компоненты читают флаг через хук `useFlag(имя)`, который возвращает значение по
умолчанию, пока ответ не пришёл.

## Значения по умолчанию

Значение по умолчанию задаётся в коде рядом с объявлением флага и описывает старое поведение.
Флаг не должен ломать страницу, если сервис флагов недоступен.

## Удаление флагов

Флаг живёт не дольше двух релизов после полного включения. Задача на удаление создаётся вместе
с флагом; линтер находит флаги, у которых истёк срок.

## Тестирование

В e2e-тестах флаги задаются явно через заголовок запроса тестового окружения, чтобы тест не
зависел от текущей раскатки.
