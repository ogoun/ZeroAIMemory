# Переменные окружения в сборке фронтенда

Фронтенд собирается Vite. Настройки, которые различаются между окружениями, — адрес API,
ключ карт, включение аналитики — приходят в сборку через переменные окружения.

## Как переменные попадают в код

В код попадают только переменные с префиксом `VITE_`. Обращение `import.meta.env.VITE_API_URL`
при сборке заменяется строкой со значением, поэтому значение фиксируется в момент сборки, а не
при запуске.

## Файлы .env

Значения для разработки лежат в `.env.development`, для локальных переопределений —
`.env.local`, который не коммитится. Значения для стендов задаёт CI при сборке.

## Одна сборка на все стенды

Чтобы не собирать фронтенд отдельно для каждого стенда, адрес API берётся из
`/config.json`, который отдаёт nginx стенда. В сборке остаются только значения, общие для всех
окружений.

## Типы

Переменные описаны в `env.d.ts`, поэтому опечатка в имени переменной ловится проверкой типов.
