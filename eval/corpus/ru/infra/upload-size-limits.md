# Пределы размера запросов на входе

Размер тела запроса ограничен на каждом звене цепочки: балансировщик, nginx, сервис. Лимиты
нужны, чтобы один клиент не занял диск и память прокси огромной загрузкой.

## Текущие значения

Общий предел nginx — 10 МБ (`client_max_body_size 10m` в блоке `http`). Маршрут загрузки
частей файлов `/upload/parts/` разрешает 64 МБ, остальные маршруты API — значение по
умолчанию. Балансировщик ограничивает тело 100 МБ.

## Буферизация

Тело больше `client_body_buffer_size` nginx пишет во временный файл в
`client_body_temp_path`. Каталог вынесен на отдельный раздел с запасом места, чтобы загрузки
не заполняли корневой раздел.

## Где менять

Предел маршрута меняется в его `location` в репозитории конфигурации шлюза и выкатывается
обычным релизом. Ручные правки на серверах затираются при следующем развёртывании.

## Проверка

После изменения лимита запускается проверка: загрузка файла на 1 МБ меньше предела проходит,
на 1 МБ больше — получает отказ.
