# Файл занят: запущенный exe нельзя перезаписать

На Linux можно заменить исполняемый файл, пока программа работает: старый inode живёт, пока
процесс его держит. На Windows загрузчик открывает образ `.exe` и `.dll` без разрешения на
запись и удаление, поэтому любая попытка их перезаписать заканчивается ошибкой.

## Как выглядит

- Компоновщик MSVC: `LINK : fatal error LNK1104: cannot open file 'target\debug\app.exe'`.
- Копирование: `The process cannot access the file because it is being used by another
  process.` — это `ERROR_SHARING_VIOLATION` (32).
- Rust/Go/.NET при пересборке: `Access is denied. (os error 5)` при попытке удалить или
  заменить бинарник.
- Обновление утилиты «поверх себя» падает, если она сама и выполняет обновление.

## Кто держит файл

1. Самое частое — забытый экземпляр программы: запущенный в другом терминале сервер,
   отладчик, тестовый процесс, который не завершился.
2. Монитор ресурсов (`resmon`) → вкладка «ЦП» → «Связанные дескрипторы» → поиск по имени файла.
3. Sysinternals Handle: `handle64.exe app.exe` печатает процессы и дескрипторы.
4. PowerShell: `Get-Process | Where-Object { $_.Path -eq 'C:\src\target\debug\app.exe' }` —
   для самого exe этого достаточно.
5. Антивирус или индексатор поиска могут держать только что созданный файл секунду-две;
   повторная попытка через паузу часто помогает.

## Трюк с переименованием

Запущенный exe нельзя удалить или перезаписать, но **можно переименовать** в пределах тома:
загрузчик держит файл, а не имя. На этом построено самообновление:

```powershell
Rename-Item app.exe app.exe.old
Copy-Item new\app.exe app.exe
# app.exe.old удалить при следующем запуске
```

## Как избежать при разработке

- Перед пересборкой останавливать запущенный бинарник; в скриптах — явно
  `Stop-Process -Name app -ErrorAction SilentlyContinue`.
- Тесты, запускающие сервер, должны его гарантированно завершать, иначе следующая сборка
  упадёт на линковке.
- Для DLL, которые грузит долгоживущий процесс (IDE, плагины), копировать их во временный
  каталог перед загрузкой (shadow copy), чтобы оригинал оставался свободным.
