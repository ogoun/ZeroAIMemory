# cmd и bat-файлы: chcp 65001 и кириллица

В классической командной строке `cmd.exe` кодировку вывода задаёт кодовая страница консоли.
Для русской локали по умолчанию это 866 (OEM), а не 1251 и не UTF-8. Посмотреть текущую:

```
chcp
```

Типичная ситуация: bat-файл сохранён редактором в UTF-8, в нём `echo Сборка завершена`, а в
консоли печатается мусор. Решение — первой строкой переключить страницу:

```bat
@echo off
chcp 65001 >nul
echo Сборка завершена
```

Нюансы, на которые наступал:

- Файл сохранять в UTF-8 **без** BOM. Если BOM есть, cmd воспримет его как часть первой
  команды, и `@echo off` не сработает: в консоли появится `'я╗┐@echo' is not recognized` (три байта BOM, показанные в 866).
- `chcp` меняет страницу для всего окна, после завершения bat-файла она остаётся 65001.
  Если дальше запускаются старые утилиты, которые печатают в 866, вернуть: `chcp 866 >nul`.
- Кириллица в путях внутри bat-файла тоже требует правильной страницы, иначе
  «файл не найден».
- Для программ на Python в той же консоли пригодится `set PYTHONUTF8=1`.

`chcp` касается только консоли cmd. В PowerShell кодировку вывода определяют другие
настройки — для него есть отдельная заметка.
