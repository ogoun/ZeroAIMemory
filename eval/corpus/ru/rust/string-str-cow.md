# String, &str и Cow<str>: что принимать и что возвращать

## Короткое правило

- **Параметр функции** — `&str`, если строка только читается. `&String` в сигнатуре — лишнее
  ограничение (clippy `ptr_arg`); `&String` автоматически приводится к `&str`, обратное
  неверно.
- **Поле структуры** — `String`, если структура владеет данными и живёт долго. `&'a str`
  только для коротких представлений поверх буфера (парсер, токенизатор).
- **Функция забирает строку себе** (кладёт в структуру) — принимать `String` или
  `impl Into<String>`, чтобы вызывающий мог отдать владение без лишней копии.
- **Возвращаемое значение** — `String`, если строка создаётся; `&str`, если это часть
  входа.

## Cow: «иногда меняю, обычно нет»

`Cow<'a, str>` — это либо `Borrowed(&'a str)`, либо `Owned(String)`. Подходит, когда
функция в большинстве случаев возвращает вход как есть, а изредка — изменённую копию:

```rust
use std::borrow::Cow;

fn escape_html(s: &str) -> Cow<'_, str> {
    if !s.contains(['<', '>', '&']) {
        return Cow::Borrowed(s);            // без выделения памяти
    }
    let mut out = String::with_capacity(s.len() + 8);
    for ch in s.chars() {
        match ch {
            '<' => out.push_str("&lt;"),
            '>' => out.push_str("&gt;"),
            '&' => out.push_str("&amp;"),
            c => out.push(c),
        }
    }
    Cow::Owned(out)
}
```

`Cow<str>` разыменовывается в `&str`, так что вызывающий код почти не меняется.
`.into_owned()` превращает результат в `String`, копируя только в случае `Borrowed`.

Готовые API, которые уже возвращают `Cow`: `String::from_utf8_lossy`,
`CStr::to_string_lossy`, `Path::to_string_lossy`. В serde `Cow<'a, str>` с атрибутом
`#[serde(borrow)]` позволяет не копировать строки без экранирования.

## Частые вопросы

- **Почему `s[0]` не компилируется?** Индексация по байтам в UTF-8 не даёт символа. Нужен
  `s.chars().next()` или срез по границе символа `&s[..n]` (паника, если `n` попадает в
  середину символа).
- **`to_string()` или `to_owned()`?** Для `&str` результат одинаковый; `to_owned()` не
  проходит через `Display` и исторически был чуть быстрее, сейчас разницы нет.
- **`Box<str>` и `Arc<str>`** — для неизменяемых строк: меньше на одно слово (нет поля
  ёмкости), `Arc<str>` удобно делить между потоками без копий.
