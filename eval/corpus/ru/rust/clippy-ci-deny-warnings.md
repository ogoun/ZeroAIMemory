# Clippy в CI с -D warnings

Команда, которую держим в пайплайне:

```
cargo clippy --workspace --all-targets --all-features -- -D warnings
```

`--all-targets` захватывает тесты, примеры и бенчмарки — без него линты в `tests/` не
проверяются. Всё после `--` уходит линтеру: `-D warnings` превращает любые предупреждения
в ошибки.

Грабли:

- **`RUSTFLAGS="-D warnings"` вместо аргумента после `--`.** Работает, но смена `RUSTFLAGS`
  инвалидирует кэш сборки, и все зависимости пересобираются. Аргумент после `--` кэш не
  трогает.
- **Новая версия toolchain — новые линты.** Пайплайн краснеет без изменений в коде.
  Закрепляем версию в `rust-toolchain.toml` и обновляем её отдельным PR.
- **Локально зелено, в CI красно** из-за `--all-features`: код под редкой фичей локально
  никто не собирает.

Настройку держим в `Cargo.toml`, а не в `#![deny]` по файлам:

```toml
[workspace.lints.clippy]
unwrap_used = "warn"
needless_pass_by_value = "warn"

[lints]
workspace = true          # в каждом крейте
```

Точечные исключения — `#[expect(clippy::too_many_arguments)]` (стабильно с 1.81): в отличие
от `allow` он сам сообщит, когда исключение станет лишним.
