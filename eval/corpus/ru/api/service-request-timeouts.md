# Тайм-ауты обработки запросов в сервисах

Каждый сервис ограничивает время обработки входящего запроса и время каждого исходящего вызова.
Без этого один медленный запрос держит поток, соединение с базой и память, пока клиент давно
ушёл.

## Входящие запросы

Обработчик ограничен 30 секундами через слой тайм-аута фреймворка. При срабатывании сервис
отвечает 503 с телом ошибки и записывает в журнал маршрут и время, без параметров запроса.

## Исходящие вызовы

У HTTP-клиента — тайм-аут соединения 2 секунды и тайм-аут ответа 10 секунд. Сумма тайм-аутов
исходящих вызовов с повторами должна быть меньше тайм-аута входящего запроса, иначе клиент
получит ошибку раньше, чем сервис закончит повторы.

## Долгие операции

Выгрузки, пересчёты и импорт не выполняются в запросе: обработчик ставит задачу в очередь и
возвращает 202 с адресом статуса. Задача выполняется отдельным обработчиком очереди со своими
пределами времени.

## Отмена

Когда клиент закрывает соединение, сервис отменяет обработку: дальнейшая работа никому не нужна.
