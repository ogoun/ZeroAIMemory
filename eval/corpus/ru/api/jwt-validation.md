# Проверка JWT в сервисах

Сервисы принимают токены доступа в формате JWT, которые выпускает сервис авторизации. Каждый
сервис проверяет токен сам, без обращения к сервису авторизации на каждый запрос.

## Подпись и ключи

Токены подписаны ES256. Открытые ключи сервисы берут из JWKS по адресу сервиса авторизации и
кэшируют на час. Неизвестный `kid` в заголовке токена вызывает внеочередное обновление набора
ключей, но не чаще раза в минуту.

## Что проверяется

Подпись, `iss`, `aud` (имя сервиса), `exp` и `nbf`. Алгоритм берётся из настроек сервиса, а не
из заголовка токена: токен с `alg: none` или другим алгоритмом отвергается.

## Права

Права лежат в поле `scope` токена. Сервис сверяет их с маршрутом до вызова обработчика; ответ
при нехватке прав — 403, при плохом токене — 401.

## Отзыв

Токены доступа живут 10 минут и не отзываются по отдельности. Немедленная блокировка
пользователя делается через список заблокированных учётных записей, который сервисы читают
из Redis.
