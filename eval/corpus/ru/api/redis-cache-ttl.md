# Кэш ответов API в Redis

Сервис каталога кэширует в Redis готовые ответы тяжёлых маршрутов: дерево категорий, фильтры
категории, блоки главной страницы. Кэш стоит перед базой, браузер о нём не знает.

## Сроки жизни

Дерево категорий живёт час, фильтры — 10 минут, блоки главной — 5 минут. Срок задаётся при
записи командой `SET ... EX`, к нему добавляется случайный разброс до 10 %.

## Версия схемы в ключе

Ключ содержит версию формата ответа: `catalog:v7:tree:{locale}`. Релиз, меняющий формат,
поднимает версию, и новый код не читает старые записи — иначе после релиза клиенты получали бы
ответы в прежнем формате до истечения срока.

## Сброс

Изменение категорий в админке удаляет ключи дерева и фильтров. Полный сброс кэша — команда
`catalog-cache flush` с подтверждением, она нужна только при аварии.

## Наблюдение

На панели — доля попаданий по маршрутам, память Redis и число вытеснений. Рост вытеснений
означает, что `maxmemory` мал для текущего набора ключей.
