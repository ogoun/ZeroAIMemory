# Пагинация списков в API

Списки в API — заказы, товары, отзывы — отдаются страницами. Здесь описано, как устроена
постраничная выдача и какие параметры принимает API.

## Параметры

Клиент передаёт `limit` (по умолчанию 20, не больше 100) и непрозрачный `cursor` из ответа
предыдущей страницы. Ответ содержит `items` и `next_cursor`; `next_cursor` равен `null` на
последней странице.

## Порядок

Порядок выдачи всегда полный и однозначный: к полю сортировки добавляется `id`. Без этого две
строки с одинаковым временем создания могут поменяться местами между запросами.

## Что внутри курсора

Курсор — base64 от JSON с последними значениями полей сортировки и версией формата. Клиент не
разбирает курсор и не строит его сам.

## Общее число

Общее количество строк API не возвращает: `count(*)` по большой таблице с фильтрами дороже
самой страницы. Интерфейс показывает «ещё» вместо номера последней страницы.
