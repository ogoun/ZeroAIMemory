# Отсоединённый HEAD (detached HEAD)

Сообщение `You are in 'detached HEAD' state` пугает, но означает простую вещь: HEAD указывает
прямо на коммит, а не на ветку. Так бывает после `git checkout <хеш>`, `git checkout v1.4.0`,
во время rebase и bisect, и всегда — внутри подмодулей.

Смотреть и собирать код в таком состоянии можно спокойно. Опасно коммитить: новые коммиты ни
на одну ветку не попадают, и после переключения на другую ветку их не видно.

Если коммиты уже сделаны и их надо сохранить:

```bash
git switch -c fix/old-release      # создать ветку прямо отсюда
```

Если уже переключились и коммиты «пропали» — git при уходе печатает их хеш
(`Warning: you are leaving 2 commits behind`), а ещё они есть в `git reflog`:

```bash
git branch fix/old-release 7c3d91e
```

Чтобы не попадать в это состояние случайно, для смены веток используем `git switch`: он
отказывается переходить на тег или хеш без явного `--detach`.
